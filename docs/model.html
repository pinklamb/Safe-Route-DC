SAFEROUTE DC / PROJECT GUIDE

Safety scoring model

The complete scoring specification: spatial filtering, distance, severity weights, temporal decay, risk normalization, final score, assumptions, limitations, and proposed next steps.

Purpose

The model assigns a route a score from 0 to 100 using nearby crime records. It combines the incident severity and age, then normalizes the total by route length.

1. Spatial filtering

Count an incident when it is within 0.18 km of the route. The implementation calculates distance from each crime to the route points provided by the browser; it does not calculate the minimum distance to every point along each segment.

2. Haversine distance

Distances account for Earth's curvature. The model uses Earth's mean radius R = 6,371 km, with latitude/longitude values converted to radians.

d = 2R × atan2(√a, √(1 − a))
a = sin2(Δφ/2) + cos(φ1)cos(φ2)sin2(Δλ/2)

The route distance D is the sum of Haversine distances between consecutive route points. To avoid a zero denominator on very short paths, the model uses Dsafe = max(D, 1.0 km).

3. Incident severity weights

Crime typeWeight
Homicide5
Sex abuse4
Assault with dangerous weapon4
Robbery3
Motor vehicle theft3
Theft/auto2
Theft/other2

Incident types not listed above use a default weight of 1 in the current code.

4. Temporal decay

Older incidents contribute less. The yearly multiplier is wyear = 0.8age, where age = currentYear − crimeYear. The current code uses 2025 as its fixed current year.

5. Aggregate risk per kilometer

For each qualifying incident, multiply its type weight by its year multiplier, then add the contributions:

W = Σ(wtype,j × wyear,j)

Normalize by the safe route distance:

R = W / Dsafe

6. Final safety score

Score = 100 × exp(−0.0004 × R)

The decay constant is λ = 0.0004. The implementation rounds the result to an integer and floors the output at 0; with a nonnegative risk value, the exponential formula keeps the score at or below 100.

Assumptions

  • Incident risk adds linearly; event clusters do not get an additional cluster multiplier.
  • Fixed integer severity values are a useful approximation of relative incident risk.
  • Risk contribution decreases exponentially with incident age.
  • Incidents outside the fixed proximity threshold do not affect a route score.
  • Route safety is approximated using weighted incident density per kilometer.

Limitations

  • Weights and the decay constant are manually selected rather than fitted to verified safety outcomes.
  • The model assumes individual contributions add linearly.
  • Route-point sampling approximates a corridor around a polyline and can miss incidents between sparse points.
  • A crime score cannot represent all street conditions or predict whether an incident will occur.

Future work in the source specification

  • Calibrate weights using regression or optimization on verified feedback.
  • Integrate more current or streaming incident data.
  • Apply risk values to routing graph edges for multi-criteria path selection.
  • Evaluate a transition from fixed heuristics to a data-driven model.

SAFEROUTE DC / PROJECT GUIDE

Getting started

Set up the Node.js app and its database and map services before running the route planner.

What you need

  • Node.js 22.12 (the version declared by this project).
  • Access to a configured MySQL database containing the crimes table.
  • Valid Google Maps browser configuration for the map and directions interface.
  • Network access to the DC GIS crime data service if you run the scheduled data refresh.

Run the application locally

  1. 1
    Clone the repository
    git clone https://github.com/pinklamb/Safe-Route-DC.git
cd Safe-Route-DC
  2. 2
    Install dependencies
    npm install
  3. 3
    Set environment variables

    Provide DB_USER, DB_PASSWORD, DB_SERVER, DB_NAME, and DB_PORT. Keep local credentials in an ignored .env file; never commit real credentials.

  4. 4
    Start the server
    node server.js

    Open http://localhost:4000, or use the port assigned through PORT.

Why node server.js? The current package.json does not define an npm start script.

What happens on startup

The web server starts, then the background updater connects to MySQL and synchronizes crime data. The refresh is scheduled again about once an hour. The map page can load before this database work finishes, but score requests need a working database connection.

SAFEROUTE DC / PROJECT GUIDE

Data & limitations

The score is based on historical reports and manually selected model assumptions. This page explains data coverage and how to interpret the result.

Crime data coverage

The database updater reads the DC GIS MPD crime Feature Service. The current code iterates yearly layers from 2018 through 2025, requests records in batches, and inserts or updates them in MySQL. The data represents reported historical incidents, not every incident that occurred.

What affects a score

  • The score depends on which records are available and how their locations and categories were reported.
  • The code compares crime locations against supplied route points. Sparse geometry can miss events near the line between points.
  • The current model uses a fixed year value of 2025 for recency decay.
  • Incident weights are a heuristic and have not been shown here to predict real-world safety outcomes.

What a score cannot tell you

The model does not evaluate lighting, open businesses, sidewalks, construction, crowding, transit service, or current street conditions. It does not predict whether a person will experience crime. Consider the score alongside route distance, travel time, current local information, and your own judgment.

Use as exploratory context. SafeRoute DC is a prototype route-planning aid, not an emergency service or a verified safety assessment.
